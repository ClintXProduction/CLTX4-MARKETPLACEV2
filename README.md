# CLTX4 MARKETPLACE
Responsive electronics/IoT marketplace for GitHub Pages.

### Features
- Product catalog with search, categories and sorting
- Shopping cart using localStorage
- Demo checkout/order tracking
- Admin dashboard
- Add/edit/delete products
- Stock monitoring
- Settings UI
- Mobile responsive

### GitHub Pages
Create a repository, upload `index.html`, `style.css`, and `script.js`, then go to **Settings → Pages → Deploy from branch → main → /(root)**.

### Important
The admin panel is a frontend demo. For a real store, connect a secure backend/database, authentication, payment gateway, inventory API, shipping and server-side authorization. Never put admin passwords or payment secrets in frontend code.
